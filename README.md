# ESHVARA DESIGN ARCHITECTS — Premium Architecture & Construction Studio Website

A cinematic, award-winning architectural web experience redesigned and rebuilt from the ground up for **ESHVARA DESIGN ARCHITECTS**, based in Kulanada, Pathanamthitta, Kerala.

Built with an editorial aesthetic inspired by luxury international architectural practices and refined construction contractor brands (such as [thebuildingcontractor.com](https://www.thebuildingcontractor.com/)), grounded in the official brand brochure.

## 🎬 Advanced Motion Design System

- **Scroll Progress:** Thin antique gold gradient line pinned to the viewport top.
- **Custom Cursor:** Context-aware desktop follower with smooth spring physics, scaling on interactive elements and displaying "VIEW" / "EXPLORE" tags over project imagery.
- **Circular Motion Elements:** Slow SVG-based circular text stamps rotating continuously.
- **Page Transitions:** Fluid opacity and vertical easing on every route change via `AnimatePresence`.
- **Interactive Before & After Toggle:** Smooth switching between existing structures and proposed architectural visualisations.
- **Hover Zoom & Clip-path Reveals:** Controlled cubic-bezier transitions (`scale(1.05)`).
